# Rainbows

Every parallel of a card you chase, so the dashboard can show which you have,
which are for sale now and which are live picks. Copy this file to
`data/rainbow.md` and make it yours: add a card with its own `##` section, or
delete parallels you don't chase. Nothing here costs a Claude call.

- **Search** is the eBay search for the card; each parallel adds its own words.
- **Owned when** picks the inventory rows for this card: `set words; card number`
  (`-word` must not be in the set name). Each parallel then matches by its
  color and finish words exactly, so a Green Wave /99 is not the Green /99.
- **Numbered** is the print run (99 for /99); a listing numbered differently
  is not that parallel.
